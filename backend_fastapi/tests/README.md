# Тесты для Backend FastAPI

Этот каталог содержит комплексные тесты для всех сервисов бэкенда.

## Структура тестов

- `conftest.py` - Конфигурация и фикстуры для всех тестов
- `test_authentication.py` - Тесты для сервиса аутентификации
- `test_category_service.py` - Тесты для сервиса категорий
- `test_client_service.py` - Тесты для сервиса клиентов
- `test_company_service.py` - Тесты для сервиса компаний
- `test_ordering_service.py` - Тесты для сервиса заказов
- `test_review_service.py` - Тесты для сервиса отзывов
- `test_chat_service.py` - Тесты для сервиса чата
- `test_file_service.py` - Тесты для сервиса файлов

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

### Запуск всех тестов
```bash
pytest
```

### Запуск тестов с подробным выводом
```bash
pytest -v
```

### Запуск тестов конкретного сервиса
```bash
pytest tests/test_authentication.py
pytest tests/test_company_service.py
pytest tests/test_client_service.py
# и т.д.
```

### Запуск тестов по маркерам
```bash
pytest -m auth          # Только тесты аутентификации
pytest -m company       # Только тесты компаний
pytest -m client        # Только тесты клиентов
pytest -m category      # Только тесты категорий
pytest -m ordering      # Только тесты заказов
pytest -m review        # Только тесты отзывов
pytest -m chat          # Только тесты чата
pytest -m file          # Только тесты файлов
```

### Запуск с покрытием кода
```bash
pytest --cov=services --cov-report=html
```

## Особенности тестов

- **Изолированная тестовая БД**: Каждый тест использует отдельную БД в памяти (SQLite)
- **Моки внешних сервисов**: RabbitMQ, push-уведомления и геокодирование замокированы
- **Фикстуры пользователей**: Предустановленные тестовые пользователи (админ, клиент, компания)
- **JWT токены**: Автоматическая генерация токенов для тестовых пользователей

## Что тестируется

### Authentication Service
- Регистрация пользователей (клиент, компания)
- Вход в систему
- Получение текущего пользователя
- Смена пароля

### Category Service
- Получение всех категорий
- Создание категории (админ)
- Обновление категории
- Удаление категории
- Защита системных категорий

### Client Service
- Получение данных клиента
- Изменение данных клиента
- Создание заявки на заказ
- Получение заявок
- Изменение иконки

### Company Service
- Получение всех компаний
- Получение компаний по категории
- Заполнение данных компании
- Изменение данных компании

### Ordering Service
- Создание заказа
- Получение заказов
- Запись на услугу
- Завершение заказа
- Отмена записи

### Review Service
- Отправка отзыва
- Получение отзывов
- Редактирование отзыва (админ)
- Удаление отзыва (админ)

### Chat Service
- Отправка сообщения
- Отправка изображения
- Получение сообщений
- Отметка как прочитанного
- Получение чатов

### File Service
- Загрузка файла
- Скачивание файла
- Проверка размера файла
- Проверка дубликатов

## Примечания

- Тесты используют SQLite в памяти для быстрого выполнения
- Все внешние зависимости (RabbitMQ, push-уведомления) замокированы
- Тесты не требуют запущенных сервисов - все работает изолированно
